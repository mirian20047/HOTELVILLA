 2. PASO 1: PREPARAR EL CODIGO PARA PRODUCCION (obligatorio, 15 min)
--------------------------------------------------------------------------------
 Si despliegas tal cual, Render falla por 3 motivos. Arreglalos asi:

 A) Crear backend/requirements.txt (ahora esta VACIO):
    Activa tu venv y congela:
      cd backend
      .\venv\Scripts\Activate.ps1
      pip freeze > requirements.txt
    Debe contener minimo: fastapi, uvicorn, sqlalchemy, pymysql, pydantic,
    email-validator, python-jose, bcrypt, python-dotenv, python-multipart,
    pillow, greenlet. Verifica que requirements.txt ya no pese 0 KB.

 B) Crear backend/Procfile (arranque en Render, sin extension):
    Contenido de 1 linea:
      web: uvicorn app.main:app --host 0.0.0.0 --port $PORT
    (Render inyecta $PORT automatico, no uses 8000 fijo)

 C) Crear backend/render.yaml (opcional pero recomendado para tu informe):
    services:
      - type: web
        name: hotel-villa-roel-api
        env: python
        buildCommand: pip install -r requirements.txt
        startCommand: uvicorn app.main:app --host 0.0.0.0 --port $PORT
        envVars:
          - key: DATABASE_URL
            sync: false
          - key: SECRET_KEY
            generateValue: true

 D) Hacer config.py leer .env (tu config.py tiene URL hardcodeada root/root):
    Cambia esta linea:
      DATABASE_URL = "mysql+pymysql://root:root@localhost:3306/gestion_hotelera"
    Por:
      DATABASE_URL = os.getenv("DATABASE_URL", "mysql+pymysql://root:root@localhost:3306/gestion_hotelera")
    Asi en local sigue igual, y en Render usa la de Clever Cloud.

 E) Ampliar CORS en backend/app/main.py (ahora solo localhost):
    Cambia:
      allow_origins=["http://localhost:5173", "http://localhost:3000"]
    Por (temporal para desplegar):
      allow_origins=["http://localhost:5173", "http://localhost:3000",
        "https://tu-frontend.vercel.app"]
    Cuando tengas la URL de Vercel, reemplazala. O usa ["*"] solo para demo
    (no recomendado en prod real, pero valido para informe universitario).

 F) Frontend: crear frontend/.env.production (URL del backend):
    Contenido:
      VITE_API_URL=https://tu-backend.onrender.com/api
    Y en frontend/src/api/axios.ts cambia baseURL: '/api' por:
      baseURL: import.meta.env.VITE_API_URL || '/api'
    Asi en local usa proxy Vite, y en Vercel usa Render.

 G) Subir uploads: crea backend/.gitignore si no existe y agrega:
      venv/
      __pycache__/
      uploads/tipos/*
      !uploads/tipos/.gitkeep
    (No subas tu venv de 500MB a GitHub, Render lo instala solo)

 4. PASO 3: CREAR MYSQL GRATIS EN CLEVER CLOUD (10 min)
--------------------------------------------------------------------------------
 1. Entra a https://www.clever-cloud.com -> Sign up gratis -> Addon -> MySQL
 2. Crea addon MySQL (plan DEV free):
    Nombre: hotel-roel-db | Region: Paris o Virginia (la mas cercana)
 3. Copia las credenciales que te da (Host, Port, User, Password, Database).
    Ejemplo: mysql://uxxxx:pxxxx@host:3306/bxxxx
 4. Arma tu DATABASE_URL formato SQLAlchemy:
    mysql+pymysql://USUARIO:PASSWORD@HOST:PORT/BASE_DATOS
    Ejemplo:
    mysql+pymysql://ux123:pass123@abc-mysql.clever-cloud.com:3306/bhotel123
 5. Conectate desde MySQL Workbench con esos datos y ejecuta tu script .sql
    de creacion de tablas (el mismo que usaste en localhost). Luego inserta
    admin/recepcionista con tus hashes de backend/generar.py.
 6. Prueba: SELECT * FROM Usuarios; debe mostrar 2 filas.

 Alternativa si Clever pide tarjeta: usa https://www.alwaysdata.com (MySQL 100MB
 gratis) con los mismos pasos. Solo para pruebas rapidas: https://www.db4free.net
 (se borra cada cierto tiempo, mencionalo en tu informe).

--------------------------------------------------------------------------------
 5. PASO 4: DESPLEGAR BACKEND EN RENDER (10 min)
--------------------------------------------------------------------------------
 1. Entra a https://render.com -> New + -> Web Service -> Connect GitHub ->
    selecciona hotel_la_villa_de_roel
 2. Configura:
    Name: hotel-villa-roel-api
    Root Directory: backend
    Environment: Python 3
    Build Command: pip install -r requirements.txt
    Start Command: uvicorn app.main:app --host 0.0.0.0 --port $PORT
    Instance: Free
 3. Environment Variables (Add):
    DATABASE_URL = mysql+pymysql://... (la de Clever Cloud del paso 4)
    SECRET_KEY = pega una clave larga aleatoria (genera en https://randomkeygen.com)
    ALGORITHM = HS256
    ACCESS_TOKEN_EXPIRE_MINUTES = 480
 4. Deploy -> espera 3-5 min. Log debe decir "Uvicorn running" y "Application startup complete".
 5. Prueba en navegador:
    https://hotel-villa-roel-api.onrender.com/ -> {"mensaje":"Bienvenido..."}
    https://hotel-villa-roel-api.onrender.com/api/health -> {"status":"Conectado a MySQL exitosamente"}
    Si dice Error de conexion, revisa DATABASE_URL y que Clever permita IPs externas.
 6. Guarda tu URL backend, la necesitaras para Vercel.
    Ejemplo: https://hotel-villa-roel-api.onrender.com

 Truco anti-sleep gratis (para exposicion): crea cuenta en https://uptimerobot.com
 y agrega monitor HTTP cada 5 min a tu /api/health. Asi no se duerme en tu demo.

--------------------------------------------------------------------------------
 6. PASO 5: DESPLEGAR FRONTEND EN VERCEL (8 min)
--------------------------------------------------------------------------------
 1. Entra a https://vercel.com -> Add New Project -> Import GitHub repo
 2. Configura:
    Framework Preset: Vite (autodetecta)
    Root Directory: frontend
    Build Command: npm run build (viene de package.json: tsc -b && vite build)
    Output Directory: dist
    Install Command: npm install
 3. Environment Variables:
    VITE_API_URL = https://hotel-villa-roel-api.onrender.com/api
    (usa tu URL real del paso 5 + /api)
 4. Deploy -> te da URL: https://hotel-villa-roel.vercel.app
 5. Vuelve a Render y actualiza CORS en main.py con esa URL exacta, haz
    git push, Render redespliega solo (2 min).
 6. Prueba flujo completo:
    Abre https://hotel-villa-roel.vercel.app/login -> login admin/admin123 ->
    Dashboard debe cargar KPIs (si tarda 50s la primera vez es el sleep de Render, normal).

 Si Vercel falla build por TypeScript: revisa `npm run build` en local primero
 y corrige errores de `noUnusedLocals` antes de subir.

 Alternativa: Netlify (Build: frontend, Publish: frontend/dist) o
 Cloudflare Pages (mismo). Vercel es el mas simple para Vite.
